Applied Energistics 2 Retrofit
========================================
This is a Forge 1.16.5 mod, which ports some of the features of newer AE2 addons to 1.16.5.

Currently, this mod features:
  - Extended interface - an interface with 36 patterns slots instead of 9. 
  - Extended dual interface (If [AE2 Fluid Crafting Rework](https://www.curseforge.com/minecraft/mc-mods/ae2-fluid-crafting-rework) is installed) - a dual interface with 36 patterns slots instead of 9. 
  - Extended interface upgrade - right click an interface or a dual interface to upgrade it to the extended version without replacing it. Transfers all content and settings seamlessly.
  - Fixes [AE2 Fluid Crafting Rework](https://www.curseforge.com/minecraft/mc-mods/ae2-fluid-crafting-rework) missing loot-table files, which allows it's blocks to drop when broken.
